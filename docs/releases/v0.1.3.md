A quieter way to hear about updates, and the presenter remote on small
laptops.

## Download

| Your computer | File |
|---|---|
| Mac with an Apple chip (M1 and later) | `Vessel-0.1.3-mac-arm64.dmg` |
| Mac with an Intel chip | `Vessel-0.1.3-mac-x64.dmg` |
| Windows (any) | `Vessel-0.1.3-win.exe` |
| Windows, Intel or AMD only (smaller) | `Vessel-0.1.3-win-x64.exe` |

Already have Vessel? It offers this update within a day, or right away from
**Check for Updates…** (the Vessel menu on a Mac, Help on Windows); choose
**Download and Install**. Your songs, playlists and settings stay as they are.

Vessel isn't code-signed yet, so a new install needs one extra step. On a Mac:
**System Settings ▸ Privacy & Security ▸ Open Anyway**. On Windows: **More
info ▸ Run anyway**. The [README](https://github.com/vesselslides/vessel#download-and-install)
walks through it.

## What's new

- **A quiet Update button.** Vessel now looks for a new version each time it
  starts and every few hours while it's open. Instead of a pop-up, a new
  version shows as an **Update available** button in the toolbar, kept out of
  the way while anything is on screen (black included), so it never
  interrupts a service. Click it to download and install, or skip that
  version.

## Fixed

- **Presenter remote on small laptops.** On a short, wide screen the next
  slide was drawn over the slide on screen. The slides now shrink to fit, on
  any laptop, tablet or phone.
