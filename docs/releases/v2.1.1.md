Phones and tablets connect to the remote on Windows.

## Download

| Your computer | File |
|---|---|
| Mac with an Apple chip (M1 and later) | `Vessel-2.1.1-mac-arm64.dmg` |
| Mac with an Intel chip | `Vessel-2.1.1-mac-x64.dmg` |
| Windows (any) | `Vessel-2.1.1-win.exe` |
| Windows, Intel or AMD only (smaller) | `Vessel-2.1.1-win-x64.exe` |

Already have Vessel? Click **Update available** in the toolbar, or choose
**Check for Updates…** (the Vessel menu on a Mac, Help on Windows), then
**Download and Install**. Your songs, playlists and settings stay as they are.

Vessel isn't code-signed yet, so a new install needs one extra step. On a Mac:
**System Settings ▸ Privacy & Security ▸ Open Anyway**. On Windows: **More
info ▸ Run anyway**. The [README](https://github.com/vesselslides/vessel#download-and-install)
walks through it.

## Fixed

### Remote control

- **The right address in the QR code.** The QR code now shows the Wi-Fi or
  Ethernet address. Before, it could show a virtual adapter's address (WSL,
  Hyper-V, VirtualBox) or a VPN's, which phones can't reach. Each address
  now names its network, and clicking one puts it in the QR code.
- **Windows Firewall.** If Windows' "allow access?" prompt was missed or
  dismissed, Windows blocked phones without saying so. The Remote window now
  checks the firewall itself and, when phones can't get through, offers
  **Allow Vessel…**: after Windows asks for an administrator's OK, it adds one
  rule for the remote's ports.
